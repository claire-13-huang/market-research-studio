# Market Research Studio V0.3 — Amazon US 选品决策工作台

静态 GitHub Pages 网页：项目库、多 SKU、Excel 智能筛选与分类、关键指标 Dashboard、利润实验室、调研结论草稿和版本存档。

## 本次升级（V0.3）

- **Excel 智能识别**：优先识别筛选主表、来源表和分类依据表；本例能还原原始 273 条、价格合格 40 条、低价筛除 233 条，并按亚克力 8、木质 9、金属 1、非同类 18、待核实 4 分类。不把不同工作表的相同 ASIN 重复导入。
- **可编辑价格门槛**：导入确认时修改最低售价，按 ASIN 合并重复导入；未核实的材质和用途保留“待核实”，不凭空推断。
- **轻量竞品记录**：保存关键决策字段，保留 ASIN、分类、材质、用途、价格、估计月销、评论数、日期、证据等级、来源表行号。低价筛除项只存统计数量，原始数据通过 Excel 原件回看。
- **一眼看懂的 Dashboard**：原始规模、合格规模、核心竞品、非同类、待核实；价格带、材质分布、售价×月销及头部竞品；切换核心/替代/待核实和材质范围。
- **重复销量提示**：相同品牌、估计月销、评论数和变体数的记录提示疑似共享父体；显示未经去重与保守去重情景，**不宣称已验证父体关系**。
- **规则结论同步更新**：只统计核心和替代类，明确估计市场和财务假设，非真正 AI 接口。

## 本地与部署

- 网站可通过任何静态站点服务打开，部署到 GitHub Pages 只需将仓库根目录设置为 `main / (root)`。
- 首次 Excel 导入需要能加载 SheetJS CDN；本页并未连接外部竞品数据库，也不会上传 Excel 到 GitHub。
- **当前无云端数据库**：项目草稿保存在本浏览器 `localStorage`，完整 Excel 放在此浏览器 `IndexedDB`；更换设备、清理网站数据将使本机归档失效，务必定期保存 JSON 和原件。
- GitHub Pages 不提供真正的身份登录、多用户共享、AI API 或数据自动同步。不可将 API 密钥或采购原始数据放到公开仓库。

## 快速验收

1. 打开「智能导入」，选择本地文件 `浴缸托盘_69美元以上40条_按材质价格销量分类_保留原始数据(1).xlsx`。
2. 预览应识别 273 条原始数据、40 条价格合格（$69 及以上）与 233 条价格筛除；确认导入。
3. Dashboard 核心候选显示 8；类别总计 8+9+1+18+4 = 40；月销统计会注明保守去重情景与年化而非历史年销。
4. 在「竞品清单」切换分类、排序与显示已排除项；在「智能导入」下载原始 Excel；在右上角导出 JSON/CSV。

## 局限

不承诺所有未知 Excel 表头均能 100% 自动识别；字段缺失时用户须确认映射。没有确定父 ASIN 时的销量去重只是**风险情景**，不能用于官方市场份额测算。
